# 🏗 CraneSelect — Подбор башенных кранов

Интерактивный веб-инструмент для ориентировочного подбора башенных кранов по ключевым характеристикам.

**Live demo:** откройте `index.html` локально или включите GitHub Pages.

## Возможности

- Фильтрация по:
  - Максимальной грузоподъёмности (т)
  - Грузоподъёмности на конце стрелы (т)
  - Максимальному вылету стрелы (м)
  - Свободностоящей высоте (м)
  - Типу крана (безоголовочный / с оголовком / люффинговый / самомонтирующийся)
  - Производителю
- Оценка соответствия запросу (match score)
- Сортировка результатов
- Каталог из 20 популярных моделей (SANY, Potain, Liebherr, Zoomlion, КБ, Wolff, Terex, Comansa)
- Полностью на русском языке
- Адаптивный дизайн, тёмная тема

## Как пользоваться

1. Укажите минимальные требования в панели слева.
2. Система сразу покажет подходящие краны.
3. Используйте сортировку и сброс фильтров по необходимости.

> ⚠️ Данные носят **справочный** характер. Перед реальным выбором сверяйте актуальные load-charts производителя, учитывайте условия площадки, ветер, фундамент и логистику.

## Запуск локально

Просто откройте `index.html` в браузере. Никаких зависимостей и сборки не требуется.

Или поднимите простой сервер:

```bash
npx serve .
# или
python3 -m http.server 8000
```

## GitHub Pages

1. Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` / root
4. Сохраните — сайт будет доступен по адресу `https://def-lt.github.io/tower-crane-selector/`
